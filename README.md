# Paragon Lite Privacy Policy

This repository contains the static HTML privacy policy for Paragon Lite.

## Publish with GitHub Pages
1. Open **Settings** for this repository.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to finish deploying. The expected URL is:
   https://zulkifill.github.io/Paragon-Lite-Privacy-Policy/

The entry page is `index.html`. No build tools or paid hosting are required for a public repository.

## Before release
Confirm the policy matches the app's real data flows, current service providers, retention practices and legal obligations. Update the effective/last-updated date when the policy changes.
